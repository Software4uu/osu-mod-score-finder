osu! Mod Score Finder Beta

Diese Beta laeuft lokal. API-Daten, lokale Pfade und Score-Daten bleiben auf deinem PC und sind durch .gitignore vom GitHub-Upload ausgeschlossen.

Setup

  1. setup-beta.bat starten.
  2. Fehlende Installationspunkte auswaehlen. Vorhandene Punkte sind ausgegraut.
  3. Client ID, Client Secret, osu! stable Ordner und osu!lazer Ordner eintragen.
  4. Speichern und danach start-beta.bat starten.

osu! API

OAuth-App erstellen unter:

https://osu.ppy.sh/home/account/edit

Callback URL: http://localhost:5173/callback

Was wird lokal gespeichert?

  • .env: Client ID, Client Secret, lokale Pfade, Port.
  • data/scores.sqlite: gefundene Scores und berechnete Werte.
  • node_modules/: installierte Projekt-Abhaengigkeiten.

Nicht zu GitHub hochladen

  • .env
  • data/
  • node_modules/
  • *.log
  • lokale osu!-Datenbanken oder Replay-Dateien

Start

start-beta.bat

Danach oeffnet die App unter http://127.0.0.1:5173.

Automatischer Score-Sync

Kurz nach dem Start synchronisiert die App den zuletzt verwendeten gespeicherten Spieler. Ein Balken zeigt API-Seiten, neue Online- und lokale Scores, PP-Berechnung und die geschaetzte Restzeit. Die osu!api wird mit etwa einer Anfrage pro Sekunde genutzt; bei einem 429-Limit wartet die App und setzt automatisch fort.

Updates

Die App prueft GitHub auf eine neuere Version und zeigt den Status oben rechts an. Wenn Update verfuegbar erscheint, kann der lokale Updater gestartet werden.

  • Git-Clones werden mit git pull --ff-only origin main aktualisiert.
  • GitHub-ZIP-Downloads werden ueber das neueste ZIP aktualisiert.
  • .env, data/, node_modules/, Logs und lokale osu!-Ordner bleiben erhalten.
  • Die Update-Abfrage zeigt kurz, was neu ist.
  • Nach einem erfolgreichen Update startet die App automatisch neu.

Wichtige Filter

  • Scan-Seiten: wie viele Recent-Seiten aus der osu!api neu gesammelt werden.
  • Anzeige-Limit: wie viele Ergebnisse sichtbar sind.
  • Bester Try: entscheidet, welcher Try pro Map-Difficulty behalten wird.
  • Improvement: vergleicht letzten Try, letzte Stunde oder heutigen Tag.
  • Live-Scanner: prueft nach einer Suche automatisch auf neu gespeicherte lokale Scores.
  • Start-Sync: synchronisiert beim Programmstart den zuletzt verwendeten gespeicherten Spieler und zeigt Fortschritt sowie Restzeit.
  • Kalender: zeigt ein Monatsraster, gespielte Tage und alle gespeicherten Scores fuer einen ausgewaehlten Tag.
  • Kalender-PP-Range: filtert den Kalender z. B. auf 100pp bis 250pp und markiert das Monats-Top-Play orange.
  • Details: zeigt alle gespeicherten Tries auf derselben Map-Difficulty.
